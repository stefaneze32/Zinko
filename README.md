# Zinko — Beautiful Front-End Starter

This is the polished front-end starting point for **Zinko — Where the World Meets.**

Included:
- Branded welcome page
- Create account and login
- Verification screen
- Interest selection
- Short-video home feed
- Status/story row
- Creator profiles and verification-style badges
- Hashtags
- Likes/comments/shares UI
- Discover/search
- Trending hashtags and creator discovery
- Live discovery and Go Live setup
- Messages
- Profile
- Status composer
- Settings/privacy/safety layout
- Responsive mobile-first styling

Important: this is a front-end prototype. Production Zinko will still need a secure backend, database, authentication, verification, media storage, real-time messaging, live-stream infrastructure, notifications, moderation, payments, and security.

Open `index.html` to start.
